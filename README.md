# 小小品鉴家

农客松「智能体与物理世界」参赛原型。评价员对照实体小麦饼干的盲码试吃，口述各性状的分数，确认后直接导出 Excel。

## 开发起点

本仓库从空目录初始化。需求来源是用户描述的手工试吃表与二次录表流程。本次实现独立编写，未导入赛前田间语音填表工具的源码、数据或专利材料。首轮范围为浏览器端盲评、口述转评分、人工确认和 .xlsx 导出。

作者标记为 Codex 的提交记录本次 AI 辅助实现。提交按实际完成顺序创建。

## 现场使用

1. 组织者进入「场次设置 → 新建场次」，粘贴品种清单，每行一项，并设置需要记录的性状。系统随机分配 B-001 等盲码。对照「组织者对照表」给实物贴签，再回到工作台。
2. 在「当前评价员」填写姓名或代号。首页默认提供 20 个空白样品，可直接练习，也可在对照表里补填品种。
3. 对照实物盲码，点击麦克风，说「色泽八分，裂纹七分，酥脆度九分，粘牙度两分，风味十分」，点击「填入评分表」。可分多次口述，也可手动改分或添加备注。
4. 核对后点击「确认评分」进入下一份。当天有多人共用设备时，换人前切换评价员。进入「评价记录」可修改已确认的记录。
5. 点击「导出 Excel」。每一行对应一位评价员对一份样品的确认记录。比赛结束需要揭盲时，勾选「包含真实品种名称」。

默认量表采用 1–10 分整数。色泽与风味按满意度评分；裂纹、酥脆度和粘牙度按明显程度评分，例如粘牙度 8 比 2 更粘牙。以上是原型的量表约定，组织者可在新场次中替换评价项目并向评价员说明口径。

## 运行与验证

使用 Node.js 22 或更新版本，在仓库根目录运行：

~~~sh
node serve.cjs
~~~

打开 http://localhost:4173/ 。运行 `node --test` 可复核评分草稿、中文转写解析和 Excel 导出测试。前端资源均随仓库提供。

## 数据与语音

- 草稿与确认记录存在当前设备、当前浏览器的本地存储中。不同设备各自导出，刷新同一页面可以续评。清理站点数据会清除本机记录。
- 原型适合组织者在同一台设备上主持盲评。组织者对照表与揭盲导出在同一浏览器内可用，没有账户权限隔离。
- 语音输入调用浏览器提供的中文语音识别。浏览器可能将音频送往其语音服务。设备需允许麦克风，识别服务须可用。可以在「文字录入」中用手机输入法的语音键完成同一流程。
- 页面按性状名称、别称和显式分数匹配转写。缺项保留为空，分数冲突或超出量表会提示核对。应用不保存音频文件。
- Excel 的「评分明细」含盲码、品种、评价员、各项数值评分、备注、记录时间和场次。「盲码对照」覆盖全场样品。默认导出的品种名称为空。
- 首页饼干静物图是为此原型生成的示意配图，各盲码使用相同图像。
